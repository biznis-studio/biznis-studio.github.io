Launching a New Digital Product Checklist

A practical, repeatable checklist. Copy this into Notion, a PDF, or plain

text - it's designed to be used, not just read.

1. Before You Start

  • ☐ Write down the single outcome that defines "done" for this
  • ☐ Identify who this is for and what they already tried that didn't work
  • ☐ Block time on your calendar - checklists don't execute themselves

2. Setup

  • ☐ Gather the tools/accounts/access you'll need up front
  • ☐ Remove one blocker that you know will interrupt you mid-task
  • ☐ Set a realistic deadline and write it somewhere visible

3. Core Steps

  • ☐ Do the smallest version first - get *a* version working end to end
  • ☐ Get feedback before polishing
  • ☐ Fix the one thing that feedback flagged most often

4. Quality Check

  • ☐ Re-read/re-test as if you were seeing it for the first time
  • ☐ Check it against the "done" definition from step 1
  • ☐ Have one other person sanity-check it if possible

5. Common Mistakes to Avoid

  • ☐ Don't add scope you didn't plan for in step 1
  • ☐ Don't skip the feedback step to save time - it costs more later
  • ☐ Don't ship without checking it once more against the original goal
