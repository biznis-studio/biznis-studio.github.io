# Terminology

- **EBV** — Expected Business Value; ranking framework for backlog (cost/revenue/probability/time-to-profit/risk).
- **Winnable (SERP)** — held by small/local sites, forums, or content missing the angle; NOT an established brand/funded SaaS.
- **lead_magnet (tier)** — free product tier, used when the constraint is traffic not monetization.
- **`.claude/skills/ship`** — build → audit → commit → rebase-safe → deploy → verify-live, one command.
- **`.claude/skills/find-opportunities`** — SERP winnability check before writing any targeted content.
- **IS EFA** — Slovak state's free e-invoicing web app (under the 2027 mandatory e-invoicing law) — most competing content omits this.
